# バナーサイズ調整とメガホンアイコン配置変更

## 目標

1. **バナーサイズ**: レガシーPro版移行バナーの幅を、ウィンドウ幅一杯（Stretch）からテキスト収まる最小サイズ（Left Aligned / Auto）に変更します。
2. **メガホン配置**: PROバッジ内に配置していたメガホンアイコンを、アプリバージョン（1.x.x）の右横に独立したボタンとして移動させます。

## 変更内容

### FocusDimmer

#### [MODIFY] [MainWindow.xaml](file:///d:/Dev/FocusDimmer2/FocusDimmer2/MainWindow.xaml)

- **バナー (`Grid` at line ~520)**:
  - `HorizontalAlignment="Left"` を設定し、幅をコンテンツに合わせます。
  - 内部の「閉じるボタン」は `Grid` の右端（コンテンツの右端）に配置される状態を維持します。
- **PROバッジ (`Border` at line ~487)**:
  - 内部のボタン/アイコンを削除し、以前の "PRO" テキストのみの状態に戻します。
- **ヘッダーレイアウト (`StackPanel` at line ~476)**:
  - `AppVersion` テキストブロックの直後に、新しい「メガホンボタン」を追加します。
  - デザイン: 背景透明、オレンジ色のメガホンアイコン、ツールチップ付き。
  - 表示条件: `ProBadgeWithIconVisibility`（既存プロパティを流用、または名称変更を検討）。
- **言語選択プルダウン (`ComboBox`)**:
  - 「余白を削除」の指示に基づき、もし不要な `Margin` があれば削除、あるいは配置の微調整を行います。

## 検証計画

### 手動検証

1. **バナー**: テキストの長さに合わせたコンパクトなサイズで表示されること、閉じるボタンが右端に重ならず配置されることを確認。
2. **メガホン**:
    - PROバッジ内から消えていること。
    - アプリバージョンの右横に表示されていること。
    - クリックしてダイアログが出ることを確認。
3. **レイアウト**: ウィンドウリサイズ時の挙動を確認。
