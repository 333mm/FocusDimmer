# 修正完了: 除外リストと優先度のバグ

## 修正内容

### 1. 除外リスト削除後の輝度維持バグ

- **問題**: 「常に明るくする」リストからプロセスを削除しても、明るいまま残り続ける
- **原因**: `InvalidateCache()`のリセット値が変更後の設定値と一致し、キャッシュが有効と誤判定
- **修正**: `_isCacheValid`フラグを追加し、明示的なキャッシュ無効化を実装

### 2. 設定優先度のバグ

- **問題**: 「非アクティブモニターを全体暗転」と「すべてのウィンドウを明るく表示」が両方オンの場合、後者が優先されてしまう
- **原因**: `DimDesktopOnly`のチェックが`forceNoHoles`より先に評価されていた
- **修正**: 条件を`if (LinkedProfile.DimDesktopOnly && !forceNoHoles)`に変更
