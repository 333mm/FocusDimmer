# 実装計画：除外リスト削除後の輝度維持バグの修正

除外リスト（「常に明るくする」リスト）からアプリを削除した後も、そのアプリのウィンドウが暗くならない（明るい領域として残り続ける）問題を修正します。

## 問題の原因

`DimmerOverlay` クラスは、描画負荷を軽減するために `UpdateState` メソッド内でキャッシュ（`isSame` チェック）を行っています。
除外リストなどの設定が変更されると `InvalidateCache()` が呼ばれますが、このメソッドがリセット用に使用している値（空文字列 `""` など）が、変更後の設定値（空のリスト `""`）と一致してしまうため、キャッシュが有効であると誤判定され、再描画（`UpdateHoles`）がスキップされてしまいます。

## 変更内容

### [Component] [FocusDimmer.Components]

#### [MODIFY] [DimmerOverlay.cs](file:///d:/Dev/FocusDimmer2/FocusDimmer2/Components/DimmerOverlay.cs)

- `_isCacheValid` という boolean フィールドを追加します。
- `InvalidateCache()` メソッド内で `_isCacheValid = false;` を設定するようにします。
- `UpdateState` メソッド内の `isSame` 判定の先頭に `_isCacheValid` のチェックを追加します。
- キャッシュがヒットしなかった（`isSame` が `false`）場合に、状態更新の最後で `_isCacheValid = true;` を設定します。

## 検証プラン

### 自動テスト

- 現状、UI描画ロジックを検証するユニットテストが存在しないため、手動検証を中心に行います。

### 手動検証

1. アプリを起動し、任意のアプリ（例：メモ帳）を「除外リスト（常に明るくする）」に追加します。
2. メモ帳がアクティブでない時も明るい状態（穴が開いている状態）であることを確認します。
3. 「除外リスト」からメモ帳を削除します。
4. メモ帳が即座に暗くなる（穴が消える）ことを確認します。
5. 特に「非アクティブの時に全体を暗くする」オプションがオンの場合に、正しく暗転することを確認します。
