# ユーザーファーストなUI配置・デザイン刷新 実装計画

現状のUIを詳細にレビューし、設定項目の論理的グループ分け、視覚的階層、操作の一貫性（アライメント・統一されたコントロールサイズ・わかりやすいアイコンとキーキャップ表現）を徹底的に改善します。

## 現状の課題と改善方針

| 画面エリア | 現状の課題 | 改善方針 |
| :--- | :--- | :--- |
| **ヘッダー** | タイトル、バッジ、言語切替、バナーが縦に間延びし、コンテンツ領域を圧迫 | タイトル＋バッジ＋バージョン＋言語切替をスリムに1行でまとめ、バナーは洗練されたインフォバーとしてコンパクトに表示 |
| **左ペイン (モニター設定)** | スライダー、数値入力、チェックボックスのインデントやマージンが不均一で視線誘導が散漫 | **基本設定（色・不透明度・マージン）**、**対象と除外（デスクトップ・タスクバー等）**、**高度な減光（非アクティブ・アイドル）**、**アニメーション（PRO）**の4セクションに論理的にカード分割・整理。スライダー＋数値欄のアライメントを均一化 |
| **右ペイン (全体共通設定)** | ホットキー入力欄が通常のテキストボックスで直感的でない。除外リストの追加ボタン（`...`）がわかりにくい | ホットキーを Windows 11 風の**キーキャップバッジスタイル**（`Ctrl` + `Alt` + `Home`）に変更。除外リストの参照ボタンにわかりやすいFluentアイコン（アプリ選択・追加）を配置 |
| **プリセット & スタートアップ** | プリセット管理ボタン群やスタートアップ設定と閉じるボタンのまとまりが弱い | プリセット操作ボタンをツールバー風に美しく整列。スタートアップカードにトレイ格納ボタンを自然に統合 |

---

## 変更予定ファイル

### 1. App.xaml
- キーキャップスタイル（`HotkeyBadgeStyle` またはホットキー用TextBoxスタイル）の追加
- アイコンボタン・ツールバーボタンスタイルの洗練
- 入力欄とボタンの高さ（`32px`）の統一
- セクション見出し用の統一タイポグラフィ

### 2. MainWindow.xaml
- **左ペイン（モニター設定）**:
  - モニター選択タブの視認性向上
  - 「減光の見た目（色・不透明度・マージン）」カード
  - 「減光の対象範囲（デスクトップ・タスクバー・最前面・タイトフレーム）」カード
  - 「高度な動作とアイドル減光（PRO）」カード
  - 「フェードアニメーション（PRO）」カード
- **右ペイン（全体共通設定）**:
  - 「除外・ホワイトリスト管理」カード（アプリ選択ボタンの改善）
  - 「ショートカットキー」カード（キーキャップ風デザイン）
  - 「グローバルプリセット（PRO）」カード（すっきりとしたルールチップ表示）
  - 「スタートアップ & 動作」カード（トレイ最小化ボタン）

## 検証計画

### 1. ビルド検証
- `dotnet build FocusDimmer2/FocusDimmer.csproj -c Debug`
- `dotnet build FocusDimmer2/FocusDimmer.csproj -c Release`
- `dotnet build FocusDimmer2/FocusDimmer.csproj -p:DefineConstants="PRO" -c Release`
- 警告0・エラー0を確認。

### 2. UI/UX検証
- メインウィンドウの各カードが整然と並び、スクロールやリサイズがスムーズであること。
- 各スライダー、チェックボックス、ホットキー入力、プリセット操作、言語切替が快適に操作できること。
