# レガシーPro版移行バナーのUX改善結果

## 概要

従来、常に表示されていた「レガシーPro版ユーザー向けの移行案内バナー」に「閉じる」機能を追加しました。
ユーザーがバナーを閉じるか、一度クリックして案内を確認した場合、次回からバナーは非表示になり、代わりにヘッダーの「PRO」バッジ内に小さなメガホンアイコンが表示されるようになります。

## 実施した変更

### 1. 状態保存の実装 (`AppSettings.cs`, `MainWindow.xaml.cs`)

- `IsLegacyBannerDismissed` プロパティを追加し、設定ファイル (`settings.json`) に保存されるようにしました。
- バナーや閉じるボタンがクリックされたタイミングでこのフラグを `true` に更新します。

### 2. UIデザインの変更 (`MainWindow.xaml`)

- **バナー本体**: 右上に「×」ボタン（閉じるボタン）を追加しました。
- **PROバッジ**: `IsLegacyBannerDismissed` が有効な場合のみ、バッジ内にメガホンアイコン（📢）が表示されるようにしました。このアイコンをクリックすると、再度移行案内ダイアログを表示できます。

### 3. 表示ロジックの変更

- **バナー**: `IsLegacyPro` かつ「未確認（未Dismiss）」の場合のみ表示。
- **バッジ内アイコン**: `IsLegacyPro` かつ「確認済み（Dismissed）」の場合のみ表示。

## 結果

これにより、ユーザーは不要になった大きなバナーを非表示にして画面をすっきりさせつつ、必要に応じていつでも移行案内にアクセスできるようになります。
