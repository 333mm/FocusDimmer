# UI改善 & プロセス選択ウィンドウ調整の確認手順

ユーザーからのフィードバックに基づき、UIの「白っぽさ」解消、プロセス選択ウィンドウの位置調整、デザイン統一、翻訳適用を行いました。

## 修正内容

1. **UIのダーク化 ("Less Whitish")**:
    * ウィンドウ背景色を `#CC050505` (ほぼ黒、透明度80%) に変更し、白っぽい見た目を解消しました。より深いダークモードになっています。

2. **プロセス選択ウィンドウの改善**:
    * **出現位置**: 押下したボタンの下（画面端の場合は調整）に出現するようにしました。
    * **デザイン**:
        * メイン画面同様のアクリル効果・ダーク背景を適用。
        * **スクロールバー**: 極細・半透明のモダンなスタイルを適用しました。
    * **翻訳**: メイン画面の言語設定が正しく引き継がれ、日本語環境では日本語で表示されるようになりました。

3. **クラッシュ修正 (再確認)**:
    * 前回の修正 (WM_GETICON) により、シェル競合によるクラッシュは発生しなくなっているはずです。

## 確認手順

1. **UIの見た目**:
    * 起動し、全体的なトーンが以前より「黒く、引き締まって」いることを確認してください。

2. **プロセス選択 (ウィンドウ挙動)**:
    * 「除外設定」等の追加ボタンを押してください。
    * [ ] **位置**: ボタンのすぐ近くにウィンドウが出現するか確認してください。
    * [ ] **翻訳**: ウィンドウ内のテキスト（「アプリ選択」「更新」など）が正しく翻訳されているか確認してください。
    * [ ] **スクロールバー**: リストの右側に、細いモダンなスクロールバーが表示されているか確認してください。
    * [ ] **リスト表示**: アイコン付きでプロセス一覧が表示され、選択が可能か確認してください。

3. **動作**:
    * 通常通りアプリを追加・削除できることを確認してください。
