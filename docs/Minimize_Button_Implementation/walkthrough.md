# 最小化ボタンの設置（既存ボタンの適正化）

画面右下のボタンが、「閉じる」の見た目をしていながら機能は「最小化」であるという不一致を解消しました。

## 実施内容

### 1. ラベルとアイコンの変更

`MainWindow.xaml` のボタン定義を修正し、ユーザーが直感的に「最小化」ボタンであると認識できるようにしました。

| | 修正前 | 修正後 |
|---|---|---|
| **アイコン** | &#xE711; (× Close) | &#xE921; (ー Minimize) |
| **テキスト** | Close (タスクトレイに閉じる) | Minimize (最小化) |

### 2. 多言語対応

新しいラベルキー `BtnMinimize` を追加しました。

- **ja.json:** "最小化"
- **en.json:** "Minimize"

## 検証結果

- [x] **外観:** ボタンが「ー 最小化」のように表示されることを確認。
- [x] **動作:** ボタンを押下するとウィンドウが最小化される機能（既存実装）が維持されていることを確認。
- [x] `dotnet build` 正常終了。
