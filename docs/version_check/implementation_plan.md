# アプリバージョン表示機能の実装計画

## 目標

アプリのバージョン情報をユーザーが確認できるようにする。

## 変更内容

### FocusDimmer2/MainWindow.xaml.cs

- `AppVersion` プロパティを追加
- コンストラクタでバージョン情報を取得・設定するロジックを追加
  - Appxパッケージからの取得を試み、失敗時（デバッグ実行時など）はAssemblyから取得
  - フォーマットは `vX.Y.Z` とする

### FocusDimmer2/MainWindow.xaml

- アプリタイトル横に `AppVersion` を表示するTextBlockを追加
- 文字サイズはタイトルより小さくし、色は薄めにする

## 検証計画

### 手動検証

- アプリを起動し、タイトルの横に「vX.Y.Z」のようなバージョン番号が表示されていることを確認する。
- デバッグ実行時とパッケージ実行時の両方でクラッシュしないことを確認する。
