# アクセントカラーの視認性向上

アクセントカラーを使用したテキストやアイコン、特にプルダウン（ComboBox）内での視認性を改善しました。

## 実施内容

### 1. アクセントカラーのブースト強化

OSのアクセントカラーをアプリ内で使用する際、彩度と明度の最低値をさらに引き上げ、暗い背景でも鮮やかに見えるように調整しました。

- **修正箇所:** [ColorHelper.cs](file:///d:/Dev/FocusDimmer2/FocusDimmer2/Helpers/ColorHelper.cs)
- **調整内容:**
  - 最低彩度 (Saturation): 0.6 → **0.75**
  - 最低明度 (Value/Brightness): 0.7 → **0.8**
- **効果:** OSの設定でグレーや暗い色をアクセントカラーにしている場合でも、アプリ内では視認性の高い鮮やかな色が使用されます。

### 2. コンボボックス（プルダウン）のデザイン改善

プルダウンメニュー内のアイテムや枠線のコントラストを調整しました。

- **修正箇所:** [App.xaml](file:///d:/Dev/FocusDimmer2/FocusDimmer2/App.xaml)
- **調整内容:**
  - ドロップダウンの背景色を `#202020` から少し明るい `#252525` に変更。
  - ドロップダウンの境界線を、よりはっきりとした半透明の白 (`#40FFFFFF`) に変更。
  - 各アイテム間の視認性を高めるため、構成要素の配置とスタイルを微調整しました。
