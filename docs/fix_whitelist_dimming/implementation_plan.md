# 全画面暗転モードでのホワイトリスト適用バグ修正

## 目標

「非アクティブなモニターの全画面を暗くする」機能や「アイドル時に暗くする」機能が有効な場合でも、「常に明るくする」リスト（ホワイトリスト）に登録されたアプリケーションが暗くならずに明るいまま表示されるように修正します。

## 変更内容

### FocusDimmer.Components

#### [MODIFY] [DimmerOverlay.cs](file:///d:/Dev/FocusDimmer2/FocusDimmer2/Components/DimmerOverlay.cs)

- `UpdateHoles` メソッドを修正します。
- `forceNoHoles` が `true` の場合に即座にリターンしている処理を削除します。
- **ウィンドウ列挙ループの修正**:
  - `forceNoHoles` が `true` の場合、「常に明るくする」ウィンドウ（およびメニュー）のみを穴あけ対象として追加するように条件を厳格化します（「最前面を除外」設定などは無視します）。
- **描画処理の修正**:
  - `forceNoHoles` が `true` の場合、アクティブウィンドウとタスクバーの穴あけ処理をスキップします。
  - 前段でフィルタリングされた `specialWindows`（ホワイトリスト対象）については、そのまま穴あけ処理を実行します。

## 検証計画

### 手動検証

1. **コードレビュー**: `DimmerOverlay.UI` のロジックフローが意図通りか確認します。
2. **ビルド検証**: 変更後のプロジェクトが正常にビルドできることを確認します。
3. **ロジックシミュレーション**:
    - **ケースA**: 全画面暗転ON、ホワイトリスト外のアプリ（メモ帳など）を使用 → 全画面が暗くなる（正）。
    - **ケースB**: 全画面暗転ON、ホワイトリスト内のアプリを使用 → アプリ部分だけ明るくなる（正）。
    - **ケースC**: 通常モード → 従来通りアクティブウィンドウ等が明るくなる（正）。
