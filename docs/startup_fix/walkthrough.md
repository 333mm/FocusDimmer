# 自動起動修正の検証手順

修正が完了しました。以下の手順で動作を確認してください。

## 変更内容の概要

- **`StartupManager.cs`**: Windows API (`StartupTask`) の呼び出しを完全な非同期処理 (`async/await`) に変更し、UIスレッドのブロックを解消しました。
- **`MainWindow.xaml.cs`**: アプリ起動時の自動起動状態チェックを非同期に行うように変更し、意図しない設定上書きを防ぎました。設定変更時も非同期で処理を行うようにしました。

## 手動検証手順

### 1. ビルドと実行

Visual Studio でソリューションをビルドし、実行してください。

### 2. 現在の状態確認

アプリが起動したら、設定画面（ハンバーガーメニューまたはトレイアイコンから「設定」）を開き、「Windows起動時に自動的に開始する」のチェックボックスの状態を確認してください。

- タスクマネージャーの「スタートアップ アプリ」タブでの `Focus Dimmer` の状態と一致しているはずです。

### 3. 設定の変更テスト

1. 「Windows起動時に自動的に開始する」のチェックを **ON** にします。
   - タスクマネージャーを開き、`Focus Dimmer` が「有効」になっていることを確認します。
2. チェックを **OFF** にします。
   - タスクマネージャーで `Focus Dimmer` が「無効」になっていることを確認します。
3. 再度 **ON** にしておきます。

### 4. 再起動テスト (重要)

1. PCを再起動（またはサインアウトしてサインイン）します。
2. Windowsにログイン後、少し待ってから `Focus Dimmer` が自動的に起動することを確認してください。
   - 通知領域（タスクトレイ）にアイコンが表示されれば成功です。
   - 起動時に「バックグラウンドで起動しました」という通知が表示されるはずです。

## 注意点

- 開発中の非パッケージ版（デバッグ実行）ではレジストリ書き込みのロジックが使用されますが、Microsoft Store版（パッケージ版）では `StartupTask` API が使用されます。今回の修正は両方に対応していますが、特にパッケージ版での挙動改善を主目的としています。
