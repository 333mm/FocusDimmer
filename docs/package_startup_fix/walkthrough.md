# パッケージ版自動起動修正 確認ガイド

パッケージ版 FocusDimmer の自動起動が動作しない問題を修正しました。
以下の手順で動作確認をお願いします。

## 修正内容

- **Package.appxmanifest**: `desktop:Extension` (StartupTask) の `EntryPoint` 属性を `Windows.FullTrustApplication` に設定しました。
  - **理由**: Win32 (Desktop Bridge) アプリで `Executable` を指定する場合、`EntryPoint` には `Windows.FullTrustApplication` を設定することが必須であるため (エラー 80080204 対策)。

## 動作確認手順

1. **アプリのパッケージング**:
   - ソリューションをビルドし、新しいパッケージを作成してください。
   - または、Visual Studio からデバッグ実行でアプリを起動してください (これによりパッケージが登録されます)。

2. **自動起動の有効化**:
   - FocusDimmer アプリ内の設定画面を開き、「Windows起動時に自動的に開始する」を ON にしてください。
   - すでに ON の場合は、一度 OFF にして再度 ON に切り替えてください。

3. **タスクマネージャーの確認**:
   - タスクマネージャーを開き、「スタートアップ アプリ」タブを確認します。
   - "Focus Dimmer" が存在し、状態が「有効」になっていることを確認してください。

4. **再起動 / サインアウト**:
   - PC を再起動するか、一度サインアウトして再度サインインしてください。

5. **起動確認**:
   - デスクトップが表示されてからしばらく待ち、FocusDimmer が自動的に起動することを確認してください。
   - タスクトレイにアイコンが表示される、または通知が表示される等で確認できます。

## 注意事項

- Visual Studio からのデバッグ実行中は、自動起動の挙動が正しくテストできない場合があります。必ず一度アプリを終了し、手動起動または再起動によるテストを行ってください。
