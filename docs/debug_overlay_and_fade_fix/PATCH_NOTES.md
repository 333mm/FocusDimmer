# 更新内容

## ✨ 新機能

* **デバッグ調査モード**: 画面上で意図せず明るくなってしまう「謎の穴」の原因を特定するための機能を追加しました。
  * **機能**: マウスカーソルの下にあるウィンドウの情報（プロセス名、ウィンドウクラス、タイトル）をリアルタイムで表示します。
  * **アクセス**: 「除外設定(プロセス)」ヘッダーの右側にある「デバッグ」ボタンからON/OFFできます。
  * **分析機能**: そのウィンドウがなぜ明るくなっているのか（タスクバー、最前面ウィンドウ、メニュー等）の分析結果を表示し、対策（「常に暗くするリスト」への追加など）を提案します。
* **ヒント機能**: 「常に暗くするプロセス」の設定項目にヘルプアイコンを追加しました。GeForce Experienceなどのオーバーレイアプリを登録することで改善できる場合があることを案内しています。

## 🔧 修正・改善

* **デスクトップのフェードアウト改善**: デスクトップをクリックしてフォーカスした際、アニメーションせずに瞬時に明るくなる問題を修正し、滑らかに変化するようにしました。
* **高DPI対応**: デバッグオーバーレイが高解像度モニターや拡大率設定のある環境でもマウスカーソルに正しく追従するように調整しました。
* **多言語対応**: 新機能のテキストを全7言語に翻訳・対応しました。
