# 最小化ボタンの設置（タイトルバー）

ユーザーのご要望に基づき、ウィンドウ上部（タイトルバー相当領域）に最小化ボタンを設置しました。

## 実施内容

### 1. タイトルバーへのボタン追加

`MainWindow.xaml` のヘッダー領域（右上、言語選択の右隣）に、標準的なスタイルの最小化ボタンを追加しました。

- **配置**: ウィンドウ右上端
- **アイコン**: `xE921` (ChromeMinimize - 標準的な最小化アイコン)
- **スタイル**: `CaptionButtonStyle` (アプリ内で統一されたキャプションボタンスタイル)
- **機能**: クリック時にウィンドウを最小化 (`MinimizeButton_Click`)

### 2. 既存ボタンの復元

画面下部にあったボタンは、一時的に「最小化」に変更していましたが、ご指摘を受け元の「タスクトレイに閉じる(Close)」に戻しました。

- **アイコン**: `xE711` (ChromeClose)
- **テキスト**: `BtnClose` ("タスクトレイに閉じる")
