# Focus Dimmer Patch Notes - Version 1.4.5

## 新機能・改善

* **アプリ名とIdentityの自動同期**
  * `SyncManifest.ps1` を導入。`sanmiri.FocusDimmer` (Pro) と `sanmiri.FocusDimmerLite` (Lite) のIdentityに応じて、アプリ表示名（Focus Dimmer Pro / Focus Dimmer）を自動的に切り替える機能を追加しました。

## バグ修正

* **画面表示の不具合修正**
  * **プロパティ画面の暗転回避:** ファイルやフォルダのプロパティ画面（`#32770`）が、他のウィンドウ同様にアクティブ時に明るくなるように修正しました。「すべてのウィンドウを明るく」モード時にも適用されます。
  * **10x10pxの輝点（ゴミ）の削除:** 画面左上に小さな白い四角形が表示される問題を修正しました（20x20px未満のウィンドウを無視するように変更）。
  * **スナップレイアウトの誤検知修正:** Windowsのスナップ機能使用時に画面が明るくならないよう、`SnapLayout` 等のシステムウィンドウを除外対象に追加しました。

* **Legacy Pro検出ロジック**
  * Debugビルド環境においても既存のLegacy Proアプリ（旧版）を検出できるように調整を行い、開発時の検証プロセスを改善しました。
  * アンインストール後もPro権限を維持するためのトークン保存ロジック（`.legacy_token`）の動作を確認・確定しました。
