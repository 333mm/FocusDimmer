# 最小化ボタンの設置（標準スタイル）

ユーザーのご要望に基づき、標準のタイトルバー（ウィンドウ上部右側）にある最小化ボタンを有効化しました。

## 実施内容

### 1. 標準最小化ボタンの表示修正

アプリ全体で使用されているウィンドウスタイル (`FluentWindowStyle` in `App.xaml`) に、既に最小化ボタンが含まれていましたが、バインディングの問題で非表示になっていました。

- **修正**: `Visibility` バインディングを削除し、デフォルトで表示されるようにしました。
- **結果**: ウィンドウ右上の「閉じる」ボタンの左隣に、適切な間隔とスタイルで最小化ボタンが表示されるようになりました。

### 2. 重複ボタンの削除

前回の手順で `MainWindow.xaml` に追加していたカスタム最小化ボタンは、上記標準ボタンと重複するため削除しました。

## 検証結果

- [x] **配置**: 標準の「閉じる」ボタンの左隣に、正しいスタイルで最小化ボタンが表示されることを確認。
- [x] **動作**: ボタンをクリックするとウィンドウが最小化されることを確認（`SystemCommands.MinimizeWindowCommand` を使用）。
- [x] `dotnet build` 正常終了。
