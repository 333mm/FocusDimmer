# 修正計画：トレイ起動時の減光と設定保存の修正

## 現状の問題

1. **起動時の減光について**
    - 現在、アプリの初期化処理（減光レイヤーの作成など）が `MainWindow.Loaded` イベント内で行われています。
    - PC再起動時（トレイ起動/AutoStart）はメインウィンドウが表示されない（`Show()` が呼ばれない）ため、`Loaded` イベントが発生せず、結果として減光が開始されません。

2. **設定が保存されない問題について**
    - 初期化処理が走らないと、設定ファイルから読み込んだモニター設定（`_appSettings.Profiles`）が、メモリ上の `MonitorProfiles` に展開されません（空の状態）。
    - この状態で何か（不意なイベントなど）がトリガーとなって `RequestSave()` が走ると、空の `MonitorProfiles` で設定ファイルが上書きされ、設定が消失します。

## 修正内容

### `FocusDimmer2/MainWindow.xaml.cs`

- `Loaded` イベントハンドラ内のロジックを、新しい非同期メソッド `InitializeAppAsync()` に移動します。
- `MainWindow` のコンストラクタから `InitializeAppAsync()` を呼び出します。
- これにより、ウィンドウの表示/非表示に関わらず、アプリ起動時に確実に初期化（Storeチェック、減光開始、設定展開）が行われるようになります。

## 検証計画

- `App.xaml.cs` のロジックにより `Show()` されない場合でも、バックグラウンドでプロセスが起動し、オーバーレイウィンドウ（DimmerOverlay）が表示されることをコード上で確認します（実機動作確認はできないため、ロジックの整合性を重視）。
