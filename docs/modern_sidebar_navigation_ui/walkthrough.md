# ウォークスルー: Windows 11 主流のサイドバー・ナビゲーションUIへの刷新

従来の左右2ペイン固定分割表示から、Windows 11 の設定アプリや Microsoft PowerToys 等で標準採用されている **「左サイドバー（NavigationView）＋右側設定カード（SettingCards）」** レイアウトへの全面刷新を完了しました。

---

## 実施した主な変更内容

### 1. Windows 11 主流のサイドバー・ナビゲーション構成
- [MainWindow.xaml](file:///d:/Dev/FocusDimmer2/FocusDimmer2/MainWindow.xaml)
  - **左サイドバー（幅 240px）**:
    - アプリアイコン＋タイトル＋PRO/FREEバッジ
    - プロモバナー（控えめで洗練されたインフォバー）
    - ナビゲーションメニュー（🖥️ モニター、🎯 アプリ除外、⌨️ ショートカット、🗂️ プリセット、⚙️ 一般設定）
    - トレイ格納（最小化）ボタン
  - **右メインコンテンツエリア（幅 `*`）**:
    - 選択されたメニューに応じた設定カード群がゆったりと美しく1列で表示され、左右での二重スクロール問題を完全に解消。

### 2. ページごとの設定整理とUX向上
1. 🖥️ **モニター (Monitors)**:
   - モニター選択ピル型タブ（Display 1, Display 2...）
   - **外観と減光**: オーバーレイ色（カラープレビュー付きボタン）、不透明度スライダー（0-95%）、マージンスライダー（-50〜100px）
   - **対象と除外**: デスクトップのみ減光、タスクバー除外、最前面除外、タイトフレーム
   - **高度な動作 (PRO)**: 非アクティブ時全体減光、アイドル時減光（無操作時間・不透明度）
   - **アニメーション (PRO)**: フェードイン待機時間・アニメーション時間、フェードアウト時間
2. 🎯 **アプリ除外 (App Exclusions)**:
   - デバッグインスペクター起動トグルボタン
   - 常に明るくするプロセス一覧（参照ボタン付き）
   - 常に暗くするプロセス一覧（参照ボタン付き）
   - アクティブ時に減光させないプロセス一覧（参照ボタン付き）
3. ⌨️ **ショートカット (Shortcuts)**:
   - キーボードショートカット設定（ON/OFF、暗くする、明るくする）
4. 🗂️ **プリセット (Presets - PRO)**:
   - プリセット選択コンボボックス、新規作成・名前変更・削除ボタン
   - プロセス連動ルールチップ一覧・追加
5. ⚙️ **一般 (General)**:
   - 自動起動・管理者として実行
   - 表示言語の選択（英語、日本語、中国語、ドイツ語、スペイン語、ポルトガル語、フランス語）
   - バージョン情報 & 移行案内

### 3. 多言語対応の拡張
