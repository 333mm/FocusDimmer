# Windows 11 主流のサイドバー・ナビゲーションUIへの刷新 実装計画

Windows 11の設定アプリ、Microsoft PowerToys、Dev Homeなどで標準採用されている**主流のUIレイアウト「左側サイドバー（NavigationView）＋右側設定カード（SettingCards）」**へ全面刷新します。

現在の左右2ペイン固定表示（左右それぞれに小さなスクロールバーがあり、設定が狭い領域に詰め込まれている状態）から、現代的なWindows 11アプリとして最も使いやすく洗練された構成へと移行します。

---

### ナビゲーション項目（左サイドバー: 幅 230px）
1. 🖥️ **モニター (Monitors)**:
   - ディスプレイごとのオーバーレイ色、不透明度、マージン、対象範囲、アイドル減光、アニメーション。
2. 🎯 **アプリ除外 (App Exclusions)**:
   - アプリ一覧（常に明るく、常に暗く、除外リスト）、デバッグインスペクター。
3. ⌨️ **ショートカット (Hotkeys)**:
   - トグル、暗く、明るくのキーバインド設定（キーキャップ風デザイン）。
4. 🗂️ **プリセット (Presets - PRO)**:
   - グローバルプリセットの作成・切り替え、関連プロセスルールの管理。
5. ⚙️ **一般 (General)**:
   - スタートアップ自動起動、管理者権限実行、言語切り替え、バージョン情報、プロモバナー。

## 主な改善メリット

1. **画面の広がりと視認性の劇的向上**:
   - 左右で二重にスクロールする必要がなくなり、右側の広いキャンバスで各設定項目（スライダー、色選択、スイッチ等）がゆったりと美しく配置されます。
2. **目的の設定への素早いアクセス**:
   - 左サイドバーのメニューをクリックするだけで、探したい機能へ即座にアクセス可能。
3. **Windows 11 との完全な統一感**:
   - Windows 11 設定アプリや Microsoft PowerToys と全く同じ操作感になり、モダンで直感的なUXを提供。

## 変更予定ファイル

### 1. App.xaml
- `NavButtonStyle`（Windows 11 ナビゲーションメニュー用ボタン：角丸4px、アイコン＋テキスト、アクティブ時インジケーター）
- `SettingCardStyle`（設定カード：WinUI 3 風の洗練された枠・パディング）
- `HotkeyBadgeStyle`（キーキャップ風デザイン）

### 2. MainWindow.xaml
- 全体をサイドバー＋メインコンテンツ（1列カードレイアウト）に再構築
- 各ページ（Monitors, Exclusions, Hotkeys, Presets, General）の配置

### 3. MainWindow.xaml.cs
- サイドバーのナビゲーション選択切り替え処理（ページ表示切り替え）

## 検証計画

### 1. ビルド検証
- `dotnet build FocusDimmer2/FocusDimmer.csproj -c Debug`
- `dotnet build FocusDimmer2/FocusDimmer.csproj -c Release`
- `dotnet build FocusDimmer2/FocusDimmer.csproj -p:DefineConstants="PRO" -c Release`
- 警告0・エラー0を確認。

### 2. 動作・UX検証
- 左サイドバーの各メニュー（モニター、アプリ除外、ショートカット、プリセット、一般）を切り替えて、すべての設定が正常に操作・保存・連動できることを確認。
- 各スライダー、ホットキー、プロセス参照、カラーピッカーが快適に動作することを確認。
