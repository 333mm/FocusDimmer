# 修正内容の確認 (Walkthrough)

以下の修正と実装を行いました。

## 変更点

### 1. 自動起動の修正

- **Package.appxmanifest**: `windows.startupTask` 拡張機能を追加し、パッケージ版アプリがスタートアップに登録できるようにしました。
- **StartupManager.cs**: パッケージ版として実行されているかを検出し、パッケージ版の場合は `StartupTask` API を、非パッケージ版の場合はレジストリ（`CurrentVersion\Run`）を使用するようにロジックを分岐させました。

### 2. 自動起動時の通知とウィンドウ制御

- **App.xaml**: `StartupUri` を削除し、`App.xaml.cs` で手動でメインウィンドウを生成するように変更しました。
- **App.xaml.cs**: 起動時の引数（`/autostart`）やアクティベーションの種類（`StartupTask`）をチェックし、自動起動かどうかを判定します。
- **MainWindow.xaml.cs**: 自動起動の場合、ウィンドウを最小化＆タスクバー非表示の状態で起動し、トレイアイコンからバルーンチップ通知（「バックグラウンドで起動しました。」）を表示するようにしました。

### 3. スリープ復帰時の安定性向上

- **MainWindow.xaml.cs**: `SystemEvents_PowerModeChanged` イベントハンドラを強化しました。スリープ復帰時に、減光タイマーの再起動とオーバーレイの最前面リセットに加え、即座に状態チェック（`MonitorTimer_Tick`）を実行するようにしました。

## 検証手順

### 自動起動 (パッケージ版)

1. アプリをパッケージとしてビルド・デプロイします。
2. アプリ内の設定で「自動起動」を有効にします（タスクマネージャーの「スタートアップ」に追加されます）。
3. PCを再起動またはサインアウトしてログインし直します。
4. **結果確認**: アプリが自動的に起動し、メインウィンドウは表示されず、トレイアイコンから通知が表示されることを確認してください。

### 自動起動 (デバッグ/非パッケージ版)

1. コマンドライン引数 `/autostart` を付けて実行ファイルを起動します。
2. **結果確認**: メインウィンドウが表示されず、通知が表示されることを確認してください。

### 通常起動

1. スタートメニューなどから普通にアプリを起動します。
2. **結果確認**: メインウィンドウ（設定画面）が表示されることを確認してください。

### スリープ復帰

1. アプリを起動した状態でPCをスリープにします。
2. PCを復帰させます。
3. **結果確認**: 画面の減光（Dimmer）が正しく機能しているか確認してください。
